# Security policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release once Stateback 0.1 is
published. Pre-release source snapshots are not supported release lines.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or Security Advisory
mechanism for this repository. Do not open a public issue for a suspected
security vulnerability.

Reports involving authentication or approval bypass, credential exposure,
unsafe retry or duplicate provider mutations, journal/evidence tampering,
secret persistence, or operator authorization are especially important.
Include safe reproduction steps and affected versions without including live
credentials or sensitive provider payloads.
